# AI Multi-Mind Engine: Startup & Configuration Checklist

Follow this checklist to go from "Plugin Active" to "First Revenue" in under 60 minutes.

## 1. Technical Foundation
- [ ] **WordPress Salts**: Ensure your `wp-config.php` has unique salts (used for AES-256 encryption of your API keys).
- [ ] **HTTPS**: Verify SSL is active (required for Stripe/PayPal webhooks).
- [ ] **Permalink Structure**: Set to "Post Name" (required for REST API routes).

## 2. AI Intelligence Setup
- [ ] **Gemini API**: Get a free key from Google AI Studio and enter it in **AI SaaS Settings**.
- [ ] **OpenAI/Claude**: (Optional) Enter keys for Pro/Agency tiers.
- [ ] **Global Context**: Define your platform's "Core Philosophy" in the settings area.

## 3. Financial Integration
- [ ] **Stripe Account**: Create a Stripe account and toggle to "Live Mode."
- [ ] **Product Catalog**: Create 3 Recurring Products (Starter, Pro, Agency) and 1 One-Time Product (Mind Unlock).
- [ ] **Webhook**: Add `https://your-site.com/wp-json/amm/v1/stripe-webhook` to Stripe and copy the Signing Secret.
- [ ] **PayPal**: Configure REST API credentials and Webhook ID.

## 4. Platform Customization
- [ ] **Branding**: Upload your own logo in the Agency settings (if applicable).
- [ ] **Custom Minds**: Create at least 3 industry-specific minds to differentiate from competitors.
- [ ] **Templates**: Add 5 "Quick-Start" templates for your target niche.

## 5. Growth Activation
- [ ] **Affiliate Program**: Create your first test affiliate user to verify tracking.
- [ ] **Shared Intel**: Generate a strategy and share the public link to verify the viral loop.
- [ ] **Council Test**: Run a "Critique Mode" sequence to ensure multi-LLM orchestration is working.

---
**Checklist Complete. You are now a SaaS Owner.**
