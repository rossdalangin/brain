# Design & User Flow

## User Flow
1. **Onboarding**: Registration -> Onboarding Tour -> Dashboard.
2. **Generation**: Dashboard -> Select Mind -> Input Request -> Ignite -> View/Save Output.
3. **Collaboration**: Invite Team -> Shared Workspace -> Council Brainstorming.
4. **Subscription**: Billing -> Select Plan -> Stripe Checkout -> Success -> Access Restored.
