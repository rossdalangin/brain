# AI Multi-Mind SaaS Engine - Documentation

Welcome to the AI Multi-Mind SaaS Engine. This platform is designed to provide elite business minds on demand, built as a robust WordPress SaaS.

## Architecture
- **WordPress Core**: Handles user management, authentication, and content storage.
- **Custom Tables**: High-performance tables for subscriptions, usage metering, teams, and affiliates.
- **REST API**: Modular API endpoints for frontend-agnostic operations.
- **AI Orchestration**: Multi-LLM support (Gemini, OpenAI, Claude) with encrypted key management.

## Installation
1. Upload the `ai-multi-mind-engine` folder to `/wp-content/plugins/`.
2. Activate the plugin in the WordPress Admin.
3. Configure API keys and Payment IDs in **Settings > AI Multi-Mind Engine**.

## Shortcodes
- `[amm_dashboard]`: Main SaaS application dashboard.
- `[amm_shared_intel]`: Public view for shared AI outputs.

## Monetization
- **Stripe**: Subscription plans and one-time purchases (Mind Unlocks / Top-ups).
- **PayPal**: Alternative subscription billing gateway.
